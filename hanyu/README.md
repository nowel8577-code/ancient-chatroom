# 韓愈古人聊天室：課堂使用說明

純離線劇本＋友情考核，不需要任何 API 金鑰。學生答題會自動回傳到你的 Google 表單／試算表。

## 一、建立 Google 表單（約 5 分鐘）

1. 到 Google 表單建立新表單，新增 **5 個「簡答」題**，題目名稱依序為：
   `班級座號`、`題號`、`學生選項`、`對錯`、`累計答對`
2. 「設定」→ 回覆：**不要**開「限制為一位使用者一次回覆」、**不要**收集電子郵件、**不要**要求登入（否則學生無法送出）。
3. 右上角 ⋮ →「取得預先填入的連結」，5 題都隨便填一個字（如 1）→「取得連結」→ 複製連結。
4. 連結長得像：
   `https://docs.google.com/forms/d/e/【表單ID】/viewform?usp=pp_url&entry.111=1&entry.222=1&entry.333=1&entry.444=1&entry.555=1`
   - 【表單ID】＝ `/d/e/` 與 `/viewform` 中間那串（以 1FAIpQLS 開頭）
   - `entry.111`…`entry.555` ＝ 依題目順序的五個欄位代號
5. 打開 `config.js`，把 `formId` 與 5 個 `entry.xxxx` 換成你的。
6. 表單的「回覆」分頁 → 綠色「連結到試算表」，之後即可在試算表即時看到每位學生每題的作答。

## 一之二、兩者並用：聊天室逛一輪 → Google 表單正式作答

1. 到 script.google.com 貼上 `建立測驗表單.gs`，執行 `createForm`，取得「學生作答連結」。
2. 把該連結填進 `config.js` 的 `window.QUIZ_URL`。聊天室下方就會出現「📝 正式作答」按鈕，學生逛完主題後一鍵跳到表單。
3. 聊天室內的「🎯 友情考核」仍可當練習（有 `formId` 時也會回傳）；正式成績以表單為準。
4. 想避免重複記錄，可把 `config.js` 的 `formId` 保持「填入表單ID」，只用測驗表單收成績。

## 二、放到網路上讓全班使用

任選一個免費靜態網站服務，上傳這個資料夾（index.html、styles.css、app.js、app-data.js、config.js）：
- GitHub Pages、Netlify Drop（把資料夾拖進去即可）、Cloudflare Pages

取得網址後，做成 QR Code 投影，學生用手機掃碼即可。

## 三、課堂流程

1. 學生進入網頁，輸入「班級座號」（例：70105）。
2. 逛主題（自我介紹、得意作品、八卦趣聞、文人朋友圈）。
3. 點「🎯 友情考核」作答，每答一題就回傳一列，最後回傳「總成績」。
4. 你在試算表篩選「對錯＝錯」、依「題號」統計，就知道全班哪題最常錯。

## 注意

- 只收「班級座號」，不收全名；對話內容不會回傳。
- 先自己測試：填好 config.js 後，用手機答一題，確認試算表有新增一列。
- 瀏覽器基於跨網站限制，網頁看不到「送出成功」的回應；以試算表有沒有資料為準。
